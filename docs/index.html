Features

One post, three platforms

Write once. Each platform gets its own live preview with an accurate character counter.

Mentions that work

Type @ to find someone. They're tagged properly on each platform, using their real identity there.

Images, GIFs & video

Attach media with per-platform limit checks and alt text. Works for LinkedIn, Bluesky and X.

Import your contacts

Pull in everyone you follow on Bluesky with one click, then fill in their X and LinkedIn accounts.

Copilot account finder

An optional GitHub Copilot agent searches the web for someone's X and LinkedIn accounts.

Local and private

Runs on your computer. Credentials are encrypted in a local SQLite database and never leave it.

SocialPoster is a Blazor Server app on .NET 10 with a MudBlazor UI (light and dark themes). It works on Windows, Linux and macOS.

Quick start

Prerequisites

  • The .NET 10 SDK
  • Git
  • Optional: the GitHub Copilot CLI (or a GitHub token) for the account finder

Run it

git clone https://github.com/isaacrlevin/SocialPoster.git
cd SocialPoster/src/SocialPoster.Web
dotnet run --launch-profile http

Open http://localhost:5184. The database is created automatically on first run, so there is no migration or setup step.

Try it with nothing connected

Bluesky search and Copy text work without any account. Connect the platforms you want to publish to on the Accounts page.

To run the tests, use dotnet test from the repository root. To change the port, set ASPNETCORE_URLS, for example ASPNETCORE_URLS=http://localhost:8080 dotnet run.

Connect your accounts

Open Accounts in the sidebar. You only need to connect the platforms you want to publish to; the rest stay "copy only".

🦋Bluesky

  1. In Bluesky go to Settings → Privacy and security → App passwords and create one. Never use your main password.
  2. On the Accounts page enter your handle (for example you.bsky.social) and the app password, then click Save.
  3. Click Test login to confirm. If you're not on bsky.social, set your PDS under Advanced.

Searching for people and importing your follows only needs your handle, not a password.

𝕏X

There are two ways to post to X.

Option A: browser (free). Turn on Post via browser instead in the X card and save. Publishing then opens x.com/intent/post in a new tab with your text pre-filled, and you click Post yourself. No API access or credentials are needed. This route can't attach media files.

Option B: X API (paid plan required).

  1. Create a project and app in the X developer portal.
  2. Set the app's permissions to Read and write.
  3. Generate an Access Token and Secret for your account. Do this after setting permissions, or the tokens will be read-only.
  4. Enter the API key, API key secret, access token and access token secret, then Save and Test. The app uses OAuth 1.0a user context.
X API costs

Free X API tiers don't allow posting, and each username lookup counts against your plan. The credentials are also used by the Verify button in the contact editor.

inLinkedIn: get an access token

LinkedIn doesn't offer a "sign in and post" option for personal tools, so you create a small developer app and generate an access token for yourself. It's free and takes about five minutes. LinkedIn occasionally renames things in its portal, so labels may differ slightly.

  1. Create an app. Go to the LinkedIn Developer Portal and click Create app. Give it a name (for example "SocialPoster"), pick a LinkedIn Page to associate it with (create a free placeholder page if you don't have one), upload any logo, accept the terms and create it. If LinkedIn asks you to verify the app against the page, use Settings → Verify and have a page admin (usually you) approve it.
  2. Request the products. On the Products tab request both of these. They're self-serve and normally approved immediately:
    • Share on LinkedIn, which grants w_member_social and is needed to post
    • Sign In with LinkedIn using OpenID Connect, which grants openid and profile and is used to find out who you are
  3. Generate a token. Open the OAuth token generator, choose your app, tick the scopes openid, profile and w_member_social, and click Request access token. Sign in and allow access.
  4. Copy the token. It's a long string that usually starts with AQ.
  5. Paste it into SocialPoster. Go to Accounts → LinkedIn, paste it into Access token and click Save. The app verifies it with LinkedIn and shows "Connected as your name".
  6. Fix version errors if they appear. If LinkedIn rejects posts with a version error, change the API version field (format YYYYMM) to a more recent month.
Tokens expire

LinkedIn access tokens last about 60 days. When posting starts failing with an authorization error, repeat steps 3 to 5 to generate a fresh one. SocialPoster uses the token as-is: it never requests or revokes tokens, and Forget token only deletes the local copy.

Prefer to run the standard OAuth flow yourself? Add http://localhost as a redirect URL on the app's Auth tab and exchange the code for a token. Any token with the same three scopes works.

✨ Copilot account finder (optional)

A GitHub Copilot agent can search the web for someone's X and LinkedIn accounts and suggest matches. It's useful because LinkedIn has no member search and X lookups cost API requests.

  • It uses the account you signed into with copilot login. On Windows the app reads the CLI's saved token from Credential Manager. On Linux and macOS set GH_TOKEN or GITHUB_TOKEN, or paste a token under Accounts → Copilot account finder.
  • Click Test connection to check it and list the models available to you. The default is claude-haiku-4.5; a search takes about 30 to 45 seconds and uses Copilot premium requests.
  • Searches can run on demand or automatically (once per contact). Turn off the automatic search in the same card.

Using the app

Writing and mentioning people

Write your post and type @ to find people. A mention is stored as a platform-neutral token such as {@grace} that points to a contact, which holds that person's identity on each platform. Each preview shows the result for that platform, with a character counter and any warnings.

PlatformWhat's postedNeeds
X@usernameX username
Bluesky@handle plus a real mention facetHandle / DID
LinkedIn@[Name](urn:li:…) in the post textExact LinkedIn name and URN

If a contact has no account on a platform, their plain name is used and the preview shows a warning. You can override the text for any platform with Customize.

  • X counts emoji and CJK characters as 2, and every link as a fixed 23 characters.
  • Bluesky shortens links the way the official app does, stores the full URL as the link target, and attaches a link-preview card when the post contains a link.
  • LinkedIn people can't be tagged by apps without partner access. After publishing, a Tag by hand checklist lists each person with a copy button and their profile link. Company pages with a numeric ID are tagged automatically.

Images, GIFs and video

Drop files onto the Media area under the post box, or click to browse. Each platform's limits are checked live in its preview card, and you can switch a platform off to skip it. Add alt text to images for screen readers.

PlatformImagesGIFsVideo
inLinkedInUp to 20 (JPG/PNG, 10 MB each)1 (10 MB)1 (MP4, 75 KB to 500 MB, 3 s to 30 min)
🦋BlueskyUp to 4 (JPG/PNG/WebP, under 1 MB each)Not supported by Bluesky1 (MP4/MOV/WebM, 100 MB, 3 min)
𝕏X (API)Up to 4 (JPG/PNG/WebP, 5 MB each)1 (15 MB)1 (MP4/MOV, 512 MB)

A post can have images or one GIF or one video, not a mix. X's browser composer can't receive files, so attach media there by hand.

Importing your Bluesky contacts

Instead of adding people one at a time, bring in everyone you follow on Bluesky.

  1. On Accounts, enter your Bluesky handle. An app password is only needed to publish, not to import.
  2. On Contacts, click Sync Bluesky follows. A running count is shown while it works.
  3. When it finishes you'll see how many contacts were added and how many existing ones were refreshed. It's safe to run again: people are matched by their Bluesky account and never duplicated.

Each imported contact gets a template key, name, avatar and Bluesky handle. Any X or LinkedIn links in their bio are picked up automatically, and you can fill in the rest later by hand or with the Copilot finder. Large follow lists can take a minute.

Managing contacts

Every person you pick with @ is saved automatically. The Contacts page lets you search by name, key or handle, filter by whether they have X or LinkedIn linked, sort (A to Z, most used, recently used or added), and edit or delete anyone. In the editor you can link accounts, verify them, and run the Copilot finder.

Configuration

There are no API keys to put in config files: credentials are entered on the Accounts page and stored locally. The one option is the data folder.

SettingDefault
SocialPoster:DataDirectory
(env SocialPoster__DataDirectory)		%LOCALAPPDATA%\SocialPoster on Windows
~/.local/share/SocialPoster on Linux
~/Library/Application Support/SocialPoster on macOS

The folder holds socialposter.db (SQLite) and keys/ (the Data Protection key ring). Keep them together: the database can't be decrypted without keys/.

Security

Local use only

The app has no login. Anyone who can reach it can post as you, so keep it bound to localhost and don't expose it to a network or the internet.

  • Credentials are encrypted with ASP.NET Core Data Protection. On Windows the key ring is protected with DPAPI. On Linux and macOS there's no OS-level key protection, so the keys rely on owner-only file permissions (the app sets the data folder to 700). Treat the folder like an SSH key.
  • Use a Bluesky app password, never your main password.
  • Forgetting a LinkedIn token only removes the local copy; it doesn't revoke it at LinkedIn.

Limitations

  • No threads or scheduling. Media is limited to what each platform accepts, and Bluesky doesn't support GIFs.
  • LinkedIn people can't be tagged automatically unless you know their URN. The finder gets their profile URL and you tag them by hand after posting. Organization vanity lookup needs Community Management API access.
  • X lookups and posts cost money depending on your plan, unless you use the free browser option, where you click Post yourself.
  • Posting to a LinkedIn company page isn't supported; posts go from your personal account.

Troubleshooting

LinkedIn says the token is invalid or expired

Tokens last about 60 days. Generate a new one with the scopes openid, profile and w_member_social and save it again. Make sure both products (Share on LinkedIn and Sign In with LinkedIn using OpenID Connect) are approved for your app.

LinkedIn rejects posts with a version error

Change API version on the LinkedIn card to a more recent YYYYMM value.

X returns "payment required" or "forbidden"

Your API plan doesn't include posting, or the tokens were generated before you set Read and write permissions. Either regenerate the tokens, or switch to Post via browser instead.

Bluesky rejects an image

Bluesky images must be under 1 MB each and can't be mixed with video. GIFs aren't supported. Resize or compress the image and try again.

The Copilot finder says it has no token

Run copilot login, or set GH_TOKEN / GITHUB_TOKEN, or paste a GitHub token under Accounts → Copilot account finder. On Linux and macOS the saved CLI login isn't read automatically.

My credentials disappeared after moving the data folder

The database is encrypted with the keys in keys/. Move or back up the whole folder together. If the keys are lost you'll need to re-enter your credentials.

The browser blocked the new tab after publishing

For X browser posting and LinkedIn tagging, the app opens a new tab. If your pop-up blocker stops it, use the Open again or View post link in the results instead.
